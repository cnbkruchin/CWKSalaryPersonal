# ข้อมูลตัวอย่าง (Sample Data)

ไฟล์ในโฟลเดอร์นี้เป็น **ข้อมูลสมมติ** (ชื่อ, เลขบัญชี, เลขบัตรประชาชนเป็นค่าที่แต่งขึ้นทั้งหมด ไม่ใช่ข้อมูลจริงของลูกจ้างโรงเรียนจุนวิทยาคม)
ใช้สำหรับทดสอบการทำงานของระบบหลังติดตั้งเท่านั้น (เช่น ทดสอบการคำนวณ ปกส., ตกเบิก, การพิมพ์สลิป)

## วิธีใช้

เพิ่มข้อมูลผ่านหน้าเว็บ **ทะเบียนลูกจ้าง → + เพิ่มลูกจ้าง** ทีละคนตามไฟล์ `employees_sample.csv`
(ระบบไม่มีฟังก์ชันนำเข้า CSV อัตโนมัติ เพื่อป้องกันการนำเข้าข้อมูลผิดพลาดโดยไม่ตรวจสอบ — สำหรับโรงเรียนที่มีลูกจ้างจำนวนมาก
สามารถขอให้ผู้พัฒนาเพิ่มฟีเจอร์นำเข้าจาก Google Sheet ได้ในอนาคต)

ไฟล์ `salary_history_sample.csv` สาธิตกรณีตัวอย่างการเลื่อนขั้นย้อนหลังที่ทำให้เกิดเงินตกเบิก
(พนักงาน SAMPLE002 เลื่อนขั้นมีผลย้อนหลัง 2 เดือนก่อนหน้า)

**เมื่อทดสอบเสร็จแล้ว ให้ลบข้อมูลตัวอย่างออกจากทะเบียนลูกจ้างจริงก่อนเริ่มใช้งานจริง**
