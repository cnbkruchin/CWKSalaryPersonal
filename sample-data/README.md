# ข้อมูลตัวอย่าง (Sample Data)

ไฟล์ในโฟลเดอร์นี้เป็น **ข้อมูลสมมติ** (ชื่อ, เลขบัญชี, เลขบัตรประชาชนเป็นค่าที่แต่งขึ้นทั้งหมด ไม่ใช่ข้อมูลจริงของลูกจ้างโรงเรียนจุนวิทยาคม)
ใช้สำหรับทดสอบการทำงานของระบบหลังติดตั้งเท่านั้น (เช่น ทดสอบการคำนวณ ปกส., ตกเบิก, การพิมพ์สลิป)

## วิธีใช้

เพิ่มข้อมูลผ่านหน้าเว็บ **ทะเบียนลูกจ้าง → + เพิ่มลูกจ้าง** ทีละคนตามไฟล์ `employees_sample.csv`
หรือทดลองเมนู **นำเข้าข้อมูล Excel** กับไฟล์ตัวอย่าง (ระบบแสดงตัวอย่างให้ตรวจก่อนบันทึกทุกครั้ง):

| ไฟล์ | รูปแบบ |
|---|---|
| `sample-payroll-2569-09.xlsx` | แบบ "ตารางเงินเดือน" เดิมของโรงเรียน (หัวตาราง 2 แถว, ชื่อ/นามสกุลแยกช่อง, ช่องรายรับ/รายจ่าย/คงเหลือ/เลขบัญชี) — เดือนกันยายน 2569 |
| `sample-slipsheet-2569-08.xlsx` | แบบ "SlipSheet" (1 แถวต่อ 1 สลิป มีรหัสพนักงาน) — เดือนสิงหาคม 2569 |

ไฟล์ `salary_history_sample.csv` สาธิตกรณีตัวอย่างการเลื่อนขั้นย้อนหลังที่ทำให้เกิดเงินตกเบิก
(พนักงาน Cwk902 เลื่อนขั้นมีผลย้อนหลัง 2 เดือนก่อนหน้า)

รหัสพนักงานในไฟล์ตัวอย่างใช้รูปแบบ `Cwk9xx` ให้ตรงกับรูปแบบที่โรงเรียนใช้จริง (`Cwk001`, `Cwk002`, ...)
แต่เลือกช่วงเลข 9xx เพื่อไม่ให้ชนกับรหัสพนักงานจริงที่มีอยู่

**เมื่อทดสอบเสร็จแล้ว ให้ลบข้อมูลตัวอย่างออกจากทะเบียนลูกจ้างจริงก่อนเริ่มใช้งานจริง**
