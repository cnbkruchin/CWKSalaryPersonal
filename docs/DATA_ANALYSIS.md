# วิเคราะห์ไฟล์งานเดิม (Data Analysis)

เอกสารนี้สรุปโครงสร้างของไฟล์งานเดิม 3 ไฟล์ที่โรงเรียนจุนวิทยาคมใช้ทำเงินเดือนลูกจ้างชั่วคราวอยู่ในปัจจุบัน
เพื่อเป็นที่มาของโครงสร้างฐานข้อมูล (Google Sheet) และหน้าตาเอกสาร/สลิปที่ระบบใหม่ต้องผลิตให้ได้ใกล้เคียงของเดิมที่สุด

> หมายเหตุ: เอกสารนี้บันทึกเฉพาะ "โครงสร้าง" ของไฟล์ต้นฉบับ ไม่ได้คัดลอกข้อมูลส่วนบุคคลจริง (ชื่อ-สกุล, เลขบัญชี, เลขบัตรประชาชน)
> ลงใน repository เพื่อความปลอดภัยของข้อมูลลูกจ้าง

## 1. บันทึกข้อความขออนุมัติเบิกเงิน (.docx)

หนังสือราชการภายในรูปแบบ "บันทึกข้อความ" ใช้ขออนุมัติเบิกจ่ายเงินประจำเดือน ประกอบด้วย:

- หัวเรื่อง: ส่วนราชการ / ที่ / วันที่ / เรื่อง / เรียน
- ตารางสรุปยอดเบิก 3 รายการหลัก:
  1. ค่าจ้างลูกจ้างชั่วคราว ประจำเดือน (โอนผ่านธนาคาร) = **ยอดสุทธิที่จ่ายเข้าบัญชีลูกจ้างทั้งหมด**
  2. ค่าประกันสังคม (เบิกเงินสด) = เงินสมทบ ปกส. ฝั่งลูกจ้าง + ฝั่งโรงเรียน + ยอดหักอื่น ๆ ที่ต้องนำส่งเป็นเงินสด
  3. รายการเบิกเงินสดอื่น ๆ ตามวาระ (เช่น ค่างานเลี้ยงเกษียณ)
  - แถวรวม + จำนวนเงินเป็นตัวหนังสือ (ภาษาไทย)
- ช่องลงนามเห็นชอบ/อนุมัติ 4 ระดับ (เจ้าหน้าที่การเงิน → หัวหน้างบประมาณ → รองผู้อำนวยการ → ผู้อำนวยการ)

**ใช้ออกแบบ:** โมดูล "รายงาน/บันทึกขออนุมัติ" ที่สร้างอัตโนมัติจากยอดรวมของรอบจ่ายเงินเดือนแต่ละเดือน พร้อมช่องลงนามให้พิมพ์ออกมาเซ็นจริง

## 2. ไฟล์ "เงินเดือน" (.xlsx – 2 ชีต)

### ชีต `เงินเดือน` (หลักฐานการจ่ายค่าจ้าง)

ตารางหลักต่อพนักงาน 1 แถว ประกอบด้วยกลุ่มคอลัมน์:

| กลุ่ม | คอลัมน์ |
|---|---|
| ข้อมูลพนักงาน | ลำดับ, ชื่อ-สกุล, หมายเลขบัญชี, ลายมือชื่อ |
| รายรับ | เงินเดือน, ปรับฐาน, เงินเพิ่มพิเศษ, ตกเบิก (ระบุเดือนที่ตกเบิก เช่น "ตกเบิก เม.ย"), รวมรับ |
| รายจ่าย | ปกส. (5%), กองทุนเงินทดแทน, อื่น ๆ, รวมหัก |
| ผลลัพธ์ | คงเหลือ (สุทธิ), สมทบ ปกส. ฝั่งโรงเรียน, สมทบกองทุนเงินทดแทนฝั่งโรงเรียน |

ท้ายตารางมีกล่องสรุป "เงินรับ" และ "เงินหัก" 14 รายการ ที่ใช้คำนวณยอดเบิกจริงในบันทึกข้อความ (ข้อ 1.) และแปลงยอดรวมเป็นตัวหนังสือ

### ชีต `รายละเอียดเพิ่มเติม`

ตารางเดียวกันแต่จัดกลุ่มพนักงานตาม **ตำแหน่ง/กลุ่มงาน** (ครูอัตราจ้าง, เจ้าหน้าที่, พนักงานขับรถ, ภารโรง, แม่บ้าน, ยามรักษาการณ์) และมีคอลัมน์ "หมายเหตุ" 2 ช่อง
ที่บันทึกสถานะเฉพาะราย เช่น:

- วันที่เริ่มงาน / วันที่เลื่อนขั้นเงินเดือนล่าสุด ("ขึ้นแล้ว 30 เม.ย.69", "เงินเดือนเต็มขั้น")
- ประเภทการจ้าง ("ลูกจ้าง มี ปกส.", "จ้างเหมาบริการ", "งบเขต") ซึ่งเป็นตัวกำหนดว่าต้องหักสมทบ ปกส. หรือไม่

**ใช้ออกแบบ:** ฟิลด์ `Group` (ตำแหน่ง/กลุ่มงาน), `HasSSO` (มี ปกส. หรือไม่), และตาราง `SalaryHistory` ที่เก็บวันที่ปรับ/เลื่อนขั้นเงินเดือนเป็นประวัติ แทนการจดในช่องหมายเหตุแบบข้อความอิสระ

## 3. ไฟล์ "การจ่ายเงินเดือน" รายเดือน (.xlsx)

ชีตต่อเดือน (ตั้งชื่อชีตตามเดือน เช่น "กันยายน 2569") เป็นรายการโอนเงินเข้าบัญชี: ลำดับ, ชื่อ-สกุล, หมายเลขบัญชี, จำนวนเงิน (สุทธิ) — เอกสารนี้คือสิ่งที่ฝ่ายการเงินยื่นให้ธนาคารเพื่อโอนเงินจริง

**ใช้ออกแบบ:** รายงาน "ใบโอนเงินธนาคาร" ที่ export ได้จากรอบจ่ายเงินเดือนที่อนุมัติแล้ว และเป็นข้อมูลตั้งต้นของ "สลิปเงินเดือน" รายบุคคลที่ลูกจ้างจะดาวน์โหลดเอง

## ข้อสังเกตสำคัญที่นำไปออกแบบระบบ

1. **ปกส. ไม่ได้หักทุกคน** — ขึ้นกับประเภทการจ้าง (ลูกจ้างที่มี ปกส. vs จ้างเหมาบริการ) → ต้องมีฟิลด์ต่อพนักงาน ไม่ใช่คำนวณอัตโนมัติแบบเดียวกันหมด
2. **โรงเรียนสมทบ ปกส. เท่ากับฝั่งลูกจ้าง (Employer match)** → ต้องคำนวณคู่กันเสมอ และมีอัตรา/เพดานเงินเดือนที่ตั้งค่าได้ (พบว่าบางรายไม่ตรงสูตร 15,000 เพดานมาตรฐานเป๊ะ ๆ จึงต้องให้แก้ไขยอดต่อรายได้ในรอบจ่ายจริง)
3. **"ตกเบิก" เป็นรายการแยกจากเงินเดือนปกติ** ผูกกับเดือนที่ปรับขึ้นจริง (ระบุหมายเหตุ เช่น "ตกเบิก เม.ย.") → ต้องมีคิวตกเบิก (Back-pay queue) ที่คำนวณอัตโนมัติเมื่อมีการเลื่อนขั้นย้อนหลัง แล้วให้แอดมินเลือกดึงเข้ารอบจ่ายเดือนใดก็ได้
4. **ยอดขออนุมัติเบิกในบันทึกข้อความ = ยอดสุทธิเข้าบัญชี + เงินสมทบ ปกส. (ลูกจ้าง+โรงเรียน) + รายการหักอื่น ๆ ที่ต้องเบิกเป็นเงินสด** → ระบบต้องแยกหมวดหมู่ "รายการหักอื่นๆ" (เงินยืม, ค่าเกษียณ, อื่นๆ) เพื่อรวมยอดให้ตรงกับรูปแบบบันทึกข้อความเดิม
5. ไม่พบเทมเพลต "สลิปเงินเดือนรายบุคคล" ในไฟล์ต้นฉบับ (มีแต่ยอดรวมทั้งโรงเรียน) — ระบบใหม่จึงออกแบบสลิป A5 แนวนอนขึ้นใหม่ โดยใช้ชุดข้อมูล/หมวดหมู่เดียวกับตาราง "เงินเดือน" ข้างต้น
