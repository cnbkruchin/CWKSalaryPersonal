# คู่มือติดตั้งระบบ (Deployment Guide)

ระบบทั้งหมด (หน้าเว็บ + ฐานข้อมูล + ตรรกะการคำนวณ) รันอยู่บน **Google Apps Script ตัวเดียว** ไม่ต้องมีเซิร์ฟเวอร์แยก
ไม่มีค่าใช้จ่าย และดูแลต่อได้ง่ายด้วยบัญชี Google ของโรงเรียนเอง

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### วิธีที่ 1 — คัดลอกไฟล์ด้วยมือ (ไม่ต้องลงโปรแกรมเพิ่ม แนะนำสำหรับผู้ดูแลทั่วไป)

1. ไปที่ [script.google.com](https://script.google.com) → **โปรเจกต์ใหม่** ตั้งชื่อว่า "ระบบเงินเดือนลูกจ้าง จุนวิทยาคม"
2. ลบไฟล์ `Code.gs` เริ่มต้นทิ้ง แล้วสร้างไฟล์ใหม่ตามรายชื่อในโฟลเดอร์ `apps-script/` ของโปรเจกต์นี้ทีละไฟล์
   (ปุ่ม `+` ข้าง Files → เลือก "Script" สำหรับไฟล์ `.gs` และ "HTML" สำหรับไฟล์ `.html`) แล้ววางเนื้อหาให้ตรงกัน
   - ไฟล์สคริปต์ (.gs): `Code`, `Utils`, `SheetService`, `Auth`, `Employees`, `SalaryHistory`, `Payroll`, `Reports`
   - ไฟล์หน้าเว็บ (.html): `Index`, `Styles`, `JsApi`, `JsPayslip`, `JsAuth`, `JsAdminEmployees`, `JsAdminSalary`, `JsAdminPayroll`, `JsAdminReports`, `JsAdminSettings`, `JsEmployeePortal`, `JsMain`
3. เปิดไฟล์ `appsscript.json` (คลิก ⚙️ Project Settings → ติ๊ก "Show appsscript.json manifest file" ก่อน) แล้ววางค่าตามไฟล์ `apps-script/appsscript.json`
4. เลือกฟังก์ชัน `initializeSystem` ที่แถบด้านบน แล้วกด **Run** (ครั้งแรกจะขอสิทธิ์ Google Sheets/Drive — กด "อนุญาต")
   ดูผลลัพธ์ที่แท็บ "Execution log": จะมีลิงก์สเปรดชีตฐานข้อมูลที่สร้างให้อัตโนมัติ
5. ไปที่ **Deploy → New deployment**
   - ประเภท: **Web app**
   - Execute as: **User accessing the web app** (ต้องตั้งใน `appsscript.json` ให้ตรงกัน — ดูข้อ 6)
   - Who has access: **Anyone within [โดเมนโรงเรียน]** (ถ้าใช้ Google Workspace for Education) หรือ **Anyone** ถ้าต้องการให้เข้าได้แม้ไม่มีบัญชี Google
   - กด Deploy แล้วคัดลอกลิงก์เว็บแอปที่ได้ ส่งให้ลูกจ้างและแอดมินใช้งาน
6. เข้าลิงก์เว็บแอป → ล็อกอินด้วย `EmployeeID: admin`, `PIN: 123456` → ระบบจะบังคับให้ตั้งรหัสผ่านใหม่ทันที

### วิธีที่ 2 — ใช้ `clasp` (สำหรับผู้ที่คุ้นเคยกับบรรทัดคำสั่ง)

```bash
npm install -g @google/clasp
clasp login
cd apps-script
clasp create --type webapp --title "ระบบเงินเดือนลูกจ้าง จุนวิทยาคม"
clasp push
clasp deploy
```

จากนั้นเข้า Apps Script editor ของโปรเจกต์ที่สร้าง รันฟังก์ชัน `initializeSystem` หนึ่งครั้ง (ขั้นตอนที่ 4-6 ด้านบน)

## การตั้งค่าหลังติดตั้ง

1. เข้าเมนู **ตั้งค่าระบบ** (แอดมิน) → กรอกชื่อโรงเรียน, ชื่อ-ตำแหน่งผู้ลงนามในบันทึกข้อความ, อัตรา ปกส./กองทุนเงินทดแทน ให้ตรงกับปีงบประมาณปัจจุบัน
2. เข้าเมนู **ทะเบียนลูกจ้าง** → เพิ่มลูกจ้างทีละคน (หรือกรอกลงในชีต `Employees` ของสเปรดชีตฐานข้อมูลโดยตรงก็ได้ แต่ต้องคำนวณ/แฮช PIN เอง — แนะนำให้เพิ่มผ่านหน้าเว็บเสมอ)
3. เข้าเมนู **เลื่อนขั้น/ตกเบิก** → ใส่อัตราเงินเดือนตั้งต้นของแต่ละคน (ถ้ายังไม่ได้ใส่ตอนเพิ่มลูกจ้าง)
4. เข้าเมนู **รอบจ่ายเงินเดือน** → เลือกเดือน → กด "สร้าง/โหลดรอบจ่าย" → ตรวจสอบ/แก้ไขตัวเลข → กด "อนุมัติและปิดรอบ"
5. ลูกจ้างเข้าเว็บแอปเดียวกัน ล็อกอินด้วยรหัสพนักงานของตัวเอง จะเห็นสลิปเดือนที่อนุมัติแล้วทันที

## อัปเดตระบบภายหลัง

- **วิธีที่ 1**: แก้ไขเนื้อหาไฟล์ในโปรเจกต์ Apps Script ได้โดยตรง แล้วกด **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version → Deploy** (การกด "Run" ในหน้าแก้ไขจะไม่อัปเดตเว็บแอปที่ deploy ไปแล้ว ต้องสร้างเวอร์ชันใหม่เสมอ)
- **วิธีที่ 2 (clasp)**: `clasp push` แล้ว `clasp deploy` เพื่อสร้างเวอร์ชันใหม่

## ข้อมูลสำรอง / ความปลอดภัย

- ฐานข้อมูลทั้งหมดอยู่ในไฟล์ Google Sheet เดียว (ลิงก์ดูได้จาก Execution log ตอนรัน `initializeSystem`, หรือค้นหาชื่อ "ฐานข้อมูลระบบเงินเดือนลูกจ้าง - โรงเรียนจุนวิทยาคม" ใน Google Drive ของบัญชีที่รัน) — Google Sheet มีระบบ Version history ในตัว (File → Version history) กู้คืนย้อนหลังได้
- แนะนำให้แชร์สเปรดชีตนี้เฉพาะแอดมินเท่านั้น (ห้ามแชร์ตรงให้ลูกจ้างทั่วไป) เพราะมีข้อมูลบัญชีธนาคาร/เลขบัตรประชาชน — ลูกจ้างเข้าถึงข้อมูลของตัวเองผ่านเว็บแอปเท่านั้น
- รหัสผ่าน (PIN) ถูกแฮชด้วย SHA-256 พร้อม salt เฉพาะราย + pepper กลางของระบบ ไม่มีการเก็บรหัสผ่านแบบข้อความล้วน
- ควรเปลี่ยนค่า `SessionTimeoutMinutes` ในตั้งค่าระบบตามความเหมาะสม (ค่าเริ่มต้น 480 นาที)
