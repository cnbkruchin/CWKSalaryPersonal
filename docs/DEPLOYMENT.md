# คู่มือติดตั้งและเปิดใช้งานระบบ

ระบบทั้งหมด (หน้าบ้าน + หลังบ้าน + ฐานข้อมูล) รันอยู่บน **Google Apps Script ตัวเดียว** ไม่ต้องมีเซิร์ฟเวอร์ ไม่มีค่าใช้จ่าย

## 1. ติดตั้งครั้งแรก

### วิธีที่ 1 — คัดลอกไฟล์ด้วยมือ (แนะนำ)

1. ใช้บัญชี Google ของงานการเงินโรงเรียน (บัญชีนี้จะเป็นเจ้าของฐานข้อมูล) ไปที่ [script.google.com](https://script.google.com) → **โปรเจกต์ใหม่**
   ตั้งชื่อ "ระบบเงินเดือนลูกจ้าง จุนวิทยาคม"
2. ลบ `Code.gs` เริ่มต้น แล้วสร้างไฟล์ให้ครบตามโฟลเดอร์ `apps-script/` (ปุ่ม `+` → Script สำหรับ `.gs`, HTML สำหรับ `.html`) วางเนื้อหาให้ตรงกัน
   - Script (.gs): `Code`, `Utils`, `SheetService`, `Auth`, `Employees`, `SalaryHistory`, `Payroll`, `Reports`, `Import`, `Documents`
   - HTML: `Index`, `Styles`, `JsApi`, `JsI18n`, `JsPayslip`, `JsAuth`, `JsEmployeePortal`, `JsVerify`, `JsAdminDashboard`, `JsAdminEmployees`,
     `JsAdminSalary`, `JsAdminPayroll`, `JsDocuments`, `JsAdminReports`, `JsAdminAudit`, `JsAdminImport`, `JsAdminSettings`, `JsMain`
3. ⚙️ Project Settings → ติ๊ก **Show "appsscript.json" manifest file** → เปิด `appsscript.json` แล้ววางค่าตาม `apps-script/appsscript.json`
   และตรวจว่า Time zone เป็น `Asia/Bangkok`
4. เลือกฟังก์ชัน `initializeSystem` → **Run** → อนุญาตสิทธิ์ที่ขอ
   ดู Execution log: จะมีลิงก์ Google Sheet ฐานข้อมูลที่ระบบสร้างให้
5. **Deploy → New deployment → Web app**
   - Execute as: **Me** (บัญชีเจ้าของ) — สคริปต์เข้าถึงฐานข้อมูลแทนผู้ใช้ ลูกจ้างจึงไม่ต้องมีสิทธิ์ในชีต
   - Who has access: **Anyone** (ลูกจ้างส่วนใหญ่ไม่มีบัญชี Google ของโรงเรียน ระบบใช้ PIN ของตัวเองยืนยันตัวตน)
   - กด Deploy แล้วคัดลอก **Web app URL**
6. เปิด `<Web app URL>?page=admin` → เข้าด้วย `admin` / `123456` → ระบบบังคับตั้งรหัสผ่านใหม่ (≥ 8 ตัวอักษร)

### วิธีที่ 2 — ใช้ `clasp`

```bash
npm install -g @google/clasp
clasp login
cd apps-script
clasp create --type webapp --title "ระบบเงินเดือนลูกจ้าง จุนวิทยาคม"
clasp push
```

จากนั้นทำขั้นตอนที่ 4–6 ด้านบน

## 2. ตั้งค่าก่อนเปิดให้ลูกจ้างใช้

1. **ตั้งค่าระบบ** — ชื่อ-ตำแหน่งเจ้าหน้าที่การเงิน (แสดงบนสลิป), ผู้ลงนามในบันทึกข้อความ, อัตรา ปกส., ช่องทางติดต่อเรื่องข้อมูลส่วนบุคคล,
   **วันจ่ายเงินเดือนตั้งต้น** และ **บัญชีธนาคารของโรงเรียน** (ธนาคาร/สาขา/ชื่อบัญชี/เลขที่บัญชี ใช้ในหนังสือถึงธนาคาร) และคำนำหน้าเลขที่หนังสือ
2. **สร้างบัญชีผู้ดูแลของเจ้าหน้าที่จริง** — ทะเบียนลูกจ้าง → เพิ่ม → ประเภทบัญชี "ผู้ดูแลระบบ" (เช่น `fin01`) ให้เจ้าหน้าที่แต่ละคนมีบัญชีของตัวเอง
   ประวัติการใช้งานจะระบุตัวผู้แก้ไขได้ชัดเจน จากนั้นปิดใช้งานบัญชี `admin` เริ่มต้น
   (บัญชีผู้ดูแลเป็นบัญชีระบบ ไม่ถูกนำเข้ารอบจ่าย — เจ้าหน้าที่ที่รับเงินเดือนด้วยให้มีบัญชีลูกจ้างแยกอีกบัญชี)
3. **เพิ่มลูกจ้าง** — ใช้รหัสรูปแบบเดิม `Cwk001`, `Cwk002`, ... ใส่อัตราเงินเดือนเริ่มต้นตอนเพิ่ม ระบบแสดง **รหัสชั่วคราว** ให้ครั้งเดียว
   (= เลขบัตรประชาชน 6 หลักท้าย หรือเลขสุ่มถ้าไม่มีเลขบัตร)
   หรือใช้เมนู **นำเข้าข้อมูล Excel** กับไฟล์เงินเดือนเดิม — ระบบสร้างลูกจ้างที่ยังไม่มีในทะเบียนให้พร้อมรหัสชั่วคราว
4. **นำเข้าเงินเดือนย้อนหลัง** (ถ้าต้องการให้ลูกจ้างโหลดสลิปเดือนเก่าได้) — นำเข้าข้อมูล Excel → เลือกไฟล์ทีละเดือน →
   ตรวจเดือน/วันที่จ่าย/การจับคู่ลูกจ้าง → นำเข้า (ไฟล์เดิมรวมหักเงินกู้และหักเงินเกษียณไว้ในช่อง "อื่นๆ" ช่องเดียว เดือนที่นำเข้าจึงแสดงเป็นรายการหักอื่นๆ)
5. **สร้างรอบจ่ายเดือนแรก** → ตรวจสอบกับไฟล์ Excel เดิมให้ตรงกัน → อนุมัติพร้อมระบุวันที่จ่าย → เมนู **เอกสารเบิกจ่าย** พิมพ์/ดาวน์โหลดเอกสารชุดเบิก

## 3. แจกให้ลูกจ้าง

- ส่งลิงก์หน้าบ้าน (`<Web app URL>` ไม่ต้องมี `?page=admin`) พร้อมรหัสพนักงาน และแจ้งรหัสชั่วคราวเป็นรายบุคคล (ไม่ส่งในกลุ่มแชต)
- แนะนำให้ "เพิ่มลงหน้าจอหลัก" บนมือถือ (Safari: แชร์ → เพิ่มลงหน้าจอหลัก / Chrome: ⋮ → เพิ่มลงในหน้าจอหลัก) ใช้เหมือนแอป
- ครั้งแรกลูกจ้างจะอ่านประกาศ PDPA และตั้ง PIN 6 หลักของตัวเอง ครั้งต่อไปกดแค่ PIN
- ลืม PIN/ถูกล็อก: เจ้าหน้าที่กด "รีเซ็ตรหัส" ที่ทะเบียนลูกจ้าง จะได้รหัสชั่วคราวใหม่และปลดล็อกทันที

## 4. อัปเดตระบบเป็นเวอร์ชันใหม่

1. แทนที่ไฟล์ใน Apps Script ด้วยไฟล์ใหม่จาก `apps-script/` (หรือ `clasp push`)
2. **รัน `initializeSystem` อีกครั้ง** — ปลอดภัย ไม่ลบข้อมูล ใช้เพิ่มคอลัมน์/ชีต/ค่าตั้งต้นใหม่ที่เวอร์ชันใหม่ต้องใช้
3. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** (ลิงก์เดิมใช้ต่อได้)
   การกด Run/Save เฉย ๆ จะไม่อัปเดตเว็บแอปที่ deploy ไปแล้ว

ก่อนอัปเดต แนะนำให้รัน `npm test` ในเครื่องนักพัฒนา (ดู README)

## 5. สำรองข้อมูลและความปลอดภัย

- ฐานข้อมูลคือ Google Sheet ไฟล์เดียว มี Version history (ไฟล์ → ประวัติเวอร์ชัน) และควร **ทำสำเนาทุกสิ้นปีงบประมาณ** (ไฟล์ → ทำสำเนา)
- **แชร์ชีตฐานข้อมูลเฉพาะเจ้าหน้าที่การเงิน** ห้ามแชร์ให้ลูกจ้าง — มีเลขบัญชีและเลขบัตรประชาชน ลูกจ้างเข้าถึงข้อมูลตัวเองผ่านเว็บแอปเท่านั้น
- ไม่แก้ไขหัวคอลัมน์ในชีตด้วยมือ และไม่แก้ชีต `AuditLog` (หลักฐานตรวจสอบย้อนหลัง)
- หน้าเว็บโหลด Tailwind CSS, ฟอนต์ Sarabun, ไลบรารี QR และ SheetJS (อ่าน/เขียน Excel) จาก CDN สาธารณะ
  (cdn.tailwindcss.com, fonts.googleapis.com, cdn.jsdelivr.net, cdnjs.cloudflare.com)
  หากเครือข่ายโรงเรียนบล็อกโดเมนเหล่านี้ หน้าเว็บจะแสดงผลไม่สวย/ไม่มี QR (รหัสตรวจสอบยังแสดงเป็นตัวอักษร) และนำเข้า/ส่งออก Excel ไม่ได้
- ไฟล์ Word ที่ดาวน์โหลดใช้ฟอนต์ TH SarabunPSK — ถ้าเครื่องไม่มีฟอนต์นี้ Word จะใช้ฟอนต์ใกล้เคียงแทน
