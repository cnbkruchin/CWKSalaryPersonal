# ระบบเงินเดือนลูกจ้างชั่วคราว — โรงเรียนจุนวิทยาคม

เว็บแอปพลิเคชันบริหารเงินเดือนลูกจ้างชั่วคราว ใช้ **Google Sheet เป็นฐานข้อมูล** และรันบน **Google Apps Script**
(ไม่ต้องมีเซิร์ฟเวอร์แยก ไม่มีค่าใช้จ่าย ดูแลได้ด้วยบัญชี Google ของโรงเรียน)
ออกแบบตามเอกสารเดิมของโรงเรียน — ดู [`docs/DATA_ANALYSIS.md`](docs/DATA_ANALYSIS.md)

ลิงก์เว็บแอปเดียว แยกเป็น 3 ทางเข้า:

| ทางเข้า | ลิงก์ | ผู้ใช้ |
|---|---|---|
| **หน้าบ้าน** | `<URL เว็บแอป>` | ลูกจ้าง — ดู/ดาวน์โหลดสลิปของตัวเอง |
| **หลังบ้าน** | `<URL เว็บแอป>?page=admin` | เจ้าหน้าที่การเงิน — จัดการเงินเดือนทั้งหมด |
| **ตรวจสอบสลิป** | `<URL เว็บแอป>?verify=รหัส` | บุคคลภายนอก เช่น ธนาคาร — ตรวจว่าสลิปเป็นของจริง |

## หน้าบ้าน (ลูกจ้าง) — ใช้ง่ายบนมือถือ

- **เข้าสู่ระบบด้วย PIN 6 หลัก** ผ่านแป้นตัวเลขขนาดใหญ่ ระบบจำรหัสพนักงานไว้ในเครื่อง ครั้งถัดไปกดแค่ PIN
- **สลิปเงินเดือน** — ยอดสุทธิเด่นชัด เลือกเดือนใดก็ได้ (ค่าเริ่มต้นเดือนล่าสุด) พิมพ์/บันทึก PDF แบบ A5 แนวนอนตามแบบฟอร์มเดิมของโรงเรียน
- **สรุปรายได้ทั้งปี** — ยอดรายได้/ประกันสังคม/สุทธิรายเดือน พิมพ์เป็นหนังสือสรุปรายได้ใช้ยื่นภาษีหรือยื่นกู้
- **ข้อมูลของฉัน** — ข้อมูลส่วนตัว (เลขบัญชี/บัตรประชาชนแสดงเฉพาะ 4 หลักท้าย) และประวัติอัตราเงินเดือน
- ครั้งแรกที่เข้าใช้: อ่าน/ยอมรับ **ประกาศความเป็นส่วนตัว (PDPA)** และตั้ง PIN ของตัวเอง
- **สองภาษา ไทย / English** — ปุ่มสลับภาษาทุกหน้า (ค่าเริ่มต้นตามภาษาของเบราว์เซอร์) สลิปแสดงหัวข้อสองภาษาและจำนวนเงินตัวอักษรเป็นภาษาอังกฤษได้
  รองรับลูกจ้างต่างชาติ และใช้ยื่นธนาคาร/สถานทูตได้

## หลังบ้าน (เจ้าหน้าที่)

- **ภาพรวม** — ยอดโอนเดือนนี้, กราฟ 6 เดือนล่าสุด, ตกเบิกค้างจ่าย, รายการที่ต้องทำก่อนปิดรอบ, กิจกรรมล่าสุด
- **รอบจ่ายเงินเดือน** — สร้างอัตโนมัติจากอัตราเงินเดือนล่าสุด (เงินประจำตำแหน่งยกมาจากเดือนก่อน), แก้ไขรายคน, ปกส. คำนวณเอง,
  อนุมัติแล้วลูกจ้างเห็นสลิปทันที; การเปิดรอบแก้ไขต้องระบุเหตุผล; ไม่ให้อนุมัติถ้ามียอดสุทธิติดลบ
- **วันที่จ่ายเงินเดือน** — ระบุตอนอนุมัติ (ค่าเริ่มต้นตามที่ตั้งไว้ เช่น วันทำการสุดท้ายของเดือน) แก้ภายหลังได้ แสดงบนสลิป เอกสารเบิกจ่าย และหนังสือถึงธนาคาร
- **เลื่อนขั้น/ตกเบิก** — ปรับเงินเดือนย้อนหลัง ระบบคำนวณตกเบิกเฉพาะเดือนที่จ่ายไปแล้ว (ไม่นับซ้ำเมื่อปรับหลายครั้ง) และปรับรอบที่ยังเป็นร่างให้ทันที
- **ทะเบียนลูกจ้าง** — ตรวจเลขบัตรประชาชนด้วย check digit, ดูว่าใครยังไม่เคยเข้าใช้/ยังใช้รหัสชั่วคราว, ออกรหัสชั่วคราวและปลดล็อกบัญชี
- **เอกสารเบิกจ่าย** — สร้างจากรอบจ่ายตามแบบฟอร์มเดิมของโรงเรียน 4 ฉบับ:
  1. **บันทึกข้อความ** ขออนุมัติเบิกเงิน (ตราครุฑ, ปีงบประมาณ, รายการ/ยอดรวม/ตัวหนังสือ, ช่องความเห็นผู้บริหาร 3 ระดับ) — แก้เลขที่หนังสือ/รายการได้ ระบบเตือนถ้ายอดไม่ตรงรอบจ่าย
  2. **ตารางเงินเดือน** (หลักฐานการจ่าย) พร้อมกล่องสรุปเงินรับ/เงินหัก 14 รายการตามเลขข้อเดิม
  3. **รายละเอียดเพิ่มเติม** (แบบรายงานงบบุคลากร) แยกตามกลุ่มงาน พร้อมหมายเหตุวันเริ่มทำงาน/ประเภทการจ้าง
  4. **เอกสารส่งธนาคาร** — หนังสือขอให้โอนเงิน + รายชื่อ เลขบัญชี จำนวนเงิน

  พิมพ์/บันทึก PDF (A4 ตั้ง/นอนตามเอกสาร), ดาวน์โหลด **Word (.doc)** แก้ไขต่อได้ หรือ **Excel (.xlsx) 3 ตาราง**
- **นำเข้าข้อมูล Excel ย้อนหลัง** — อัปโหลดไฟล์เงินเดือนเดิม (.xlsx/.xls/.csv) ระบบหาแถวหัวตาราง จับคู่คอลัมน์ ตรวจเดือนจากชื่อไฟล์/หัวเอกสาร
  และจับคู่ลูกจ้างจากรหัส/ชื่อ-สกุล/เลขบัญชีให้อัตโนมัติ แสดงตัวอย่างให้ตรวจก่อนบันทึก (แก้การจับคู่รายแถว, สร้างลูกจ้างใหม่จากไฟล์, เลือกทับรอบเดิม)
  ผลที่ได้เป็นรอบจ่ายที่อนุมัติแล้วพร้อมวันที่จ่าย — ลูกจ้างดาวน์โหลดสลิปย้อนหลังได้ทันที
- **ประวัติการใช้งาน** — บันทึกทุกการเข้าสู่ระบบและการแก้ไข (ใคร/ทำอะไร/เมื่อไร) ค้นหาและส่งออก CSV ได้
- **ตั้งค่าระบบ** — ชื่อโรงเรียน, อัตรา ปกส., ผู้ลงนาม — แก้ได้จากหน้าเว็บ ไม่ต้องแก้โค้ด

## มาตรฐานความปลอดภัยและความน่าเชื่อถือ

| ด้าน | สิ่งที่ระบบทำ |
|---|---|
| การยืนยันตัวตน | แยกทางเข้าหน้าบ้าน/หลังบ้าน สิทธิ์ต่างกัน, รหัสแฮช SHA-256 + salt รายคน + pepper, ข้อความ error เดียวกันทุกกรณีเพื่อไม่ให้เดารหัสพนักงานได้ |
| นโยบายรหัสผ่าน | ลูกจ้าง: PIN 6 หลัก ห้ามเรียง/ซ้ำ/ตรงเลขบัตร; ผู้ดูแล: ≥ 8 ตัวอักษร ไม่ใช่ตัวเลขล้วน; บัญชีใหม่/รีเซ็ตต้องตั้งรหัสใหม่ทันที |
| กันการเดารหัส | ผิด 5 ครั้งล็อก 15 นาที (ผู้ดูแลปลดล็อกได้) |
| เซสชัน | หมดอายุอัตโนมัติ, ออกจากระบบเองเมื่อไม่ใช้งาน 15 นาที, ป้องกันการฝังหน้าเว็บในเว็บอื่น (clickjacking) |
| ข้อมูลส่วนบุคคล (PDPA) | ประกาศความเป็นส่วนตัวและบันทึกการยอมรับ, ปิดบังเลขบัญชี/บัตรประชาชน, บันทึกการเข้าถึง |
| ตรวจสอบย้อนหลัง | Audit log ทุกการแก้ไขข้อมูลเงินเดือน, การเปิดรอบที่อนุมัติแล้วต้องระบุเหตุผล |
| เอกสารปลอมแปลง | สลิปที่อนุมัติแล้วมี QR + รหัสตรวจสอบ (HMAC) — แก้ตัวเลขบนสลิปแล้วตรวจไม่ผ่าน |
| ความถูกต้องของข้อมูล | ล็อกการเขียนเมื่อใช้งานพร้อมกัน (LockService), บังคับเก็บเลขบัญชี/เดือนเป็นข้อความ (Sheets ไม่ตัดเลข 0 นำหน้า), อัปเกรดคอลัมน์ชีตอัตโนมัติ |
| ทดสอบอัตโนมัติ | ชุดทดสอบ 23 กรณีรันโค้ดจริง (รวมการนำเข้า Excel และยอดเอกสารเบิกจ่ายที่ต้องตรงกัน) (`npm test`) และระบบพรีวิวในเครื่อง |

## โครงสร้างโปรเจกต์

```
apps-script/     โค้ด Google Apps Script ทั้งหมด (backend .gs + frontend .html) — ส่วนที่นำไป deploy
assets/          ตราโรงเรียน และตราครุฑสำหรับบันทึกข้อความ (ฝังเป็น base64 ใน apps-script/JsApi.html แล้ว)
dev/             เครื่องมือนักพัฒนา: จำลอง Apps Script บน Node.js, ชุดทดสอบ, เซิร์ฟเวอร์พรีวิว
docs/            DATA_ANALYSIS · SHEET_SCHEMA · DEPLOYMENT
sample-data/     ข้อมูลตัวอย่าง (สมมติ) สำหรับทดสอบ รวมไฟล์ Excel ตัวอย่างสำหรับทดลองนำเข้า
```

## เริ่มต้นใช้งาน

ดู [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) โดยสรุป: คัดลอกไฟล์ใน `apps-script/` ไปยังโปรเจกต์ Apps Script →
รัน `initializeSystem()` หนึ่งครั้ง → Deploy เป็น Web app → เข้า `?page=admin` ด้วย `admin` / `123456` แล้วตั้งรหัสผ่านใหม่

## สำหรับนักพัฒนา

ต้องมี Node.js 18 ขึ้นไป (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)

```bash
npm test        # รันชุดทดสอบตรรกะเงินเดือน/ความปลอดภัยทั้งหมด
npm run dev     # พรีวิวที่ http://localhost:8080/exec (หลังบ้าน: ?page=admin) พร้อมข้อมูลตัวอย่าง
```

ทั้งสองคำสั่งรันโค้ด `.gs` ตัวจริงบนบริการ Apps Script จำลอง (`dev/gas-runtime.js`) ซึ่งจำลองพฤติกรรมแปลงค่าอัตโนมัติของ Google Sheets ด้วย
ควรรัน `npm test` ทุกครั้งก่อนนำโค้ดใหม่ขึ้นระบบจริง

## หมายเหตุด้านข้อมูลส่วนบุคคล

repository นี้ **ไม่มีข้อมูลจริงของลูกจ้าง** เอกสารวิเคราะห์และข้อมูลตัวอย่างใช้ชื่อ/ตัวเลขสมมติทั้งหมด
ข้อมูลจริงถูกกรอกผ่านหน้า "ทะเบียนลูกจ้าง" หลังติดตั้งและเก็บเฉพาะใน Google Sheet ของโรงเรียน
