# ระบบเงินเดือนลูกจ้างชั่วคราว — โรงเรียนจุนวิทยาคม

เว็บแอปพลิเคชันบริหารจัดการเงินเดือนลูกจ้างชั่วคราว ใช้ **Google Sheet เป็นฐานข้อมูล** ทั้งหมด
รันบน **Google Apps Script** (ไม่ต้องมีเซิร์ฟเวอร์แยก ไม่มีค่าใช้จ่าย ดูแลเองได้ด้วยบัญชี Google ของโรงเรียน)

ออกแบบโดยอ้างอิงรูปแบบเอกสารเดิมของโรงเรียน (ดู [`docs/DATA_ANALYSIS.md`](docs/DATA_ANALYSIS.md)):
บันทึกข้อความขออนุมัติเบิกจ่าย, ตารางหลักฐานการจ่ายค่าจ้าง, และใบโอนเงินธนาคารรายเดือน

## ฟีเจอร์หลัก

- **จัดการทะเบียนลูกจ้าง** — ข้อมูลส่วนตัว, กลุ่มงาน, บัญชีธนาคาร, สถานะ ปกส.
- **เลื่อนขั้น/ปรับเงินเดือน พร้อมคำนวณตกเบิกอัตโนมัติ** — เมื่อปรับเงินเดือนย้อนหลัง ระบบเทียบกับรอบจ่ายที่อนุมัติไปแล้วและสร้างคิวเงินตกเบิกให้ทันที เลือกดึงเข้ารอบจ่ายเดือนใดก็ได้ภายหลัง
- **รอบจ่ายเงินเดือนรายเดือน** — สร้างอัตโนมัติจากอัตราเงินเดือนล่าสุด, แก้ไขเงินเพิ่มพิเศษ/รายการหักอื่น ๆ ได้เป็นรายคน, คำนวณ ปกส./สุทธิให้อัตโนมัติ, อนุมัติปิดรอบเพื่อเผยแพร่สลิปให้ลูกจ้าง
- **สลิปเงินเดือน A5 แนวนอน** — พิมพ์/บันทึกเป็น PDF ได้ทั้งแบบพิมพ์รวมทุกคน (ฝั่งแอดมิน) และพิมพ์เฉพาะของตัวเอง (ฝั่งลูกจ้าง)
- **พอร์ทัลลูกจ้าง** — ลูกจ้างล็อกอินด้วยรหัสพนักงาน+PIN ของตัวเอง เลือกดู/ดาวน์โหลดสลิปย้อนหลังเดือนใดก็ได้ หรือเดือนปัจจุบันโดยอัตโนมัติ
- **รายงาน/เอกสารขออนุมัติ** — สร้าง "บันทึกข้อความขออนุมัติเบิกเงิน" และ "ใบโอนเงินธนาคาร" พร้อมพิมพ์ ให้หน้าตาใกล้เคียงเอกสารราชการเดิมของโรงเรียน รวมยอดเป็นตัวหนังสือภาษาไทยอัตโนมัติ
- **ตั้งค่าระบบได้เอง** — ชื่อโรงเรียน, อัตรา ปกส./กองทุนเงินทดแทน, รายชื่อผู้ลงนาม — แก้ได้จากหน้าเว็บ ไม่ต้องแก้โค้ด

## โครงสร้างโปรเจกต์

```
apps-script/         โค้ด Google Apps Script ทั้งหมด (backend .gs + frontend .html)
assets/               ตราโรงเรียน (สกัดจากเทมเพลตสลิปเงินเดือนเดิม) — ฝังเป็น base64 ไว้ใน apps-script/JsApi.html แล้ว
docs/
  DATA_ANALYSIS.md    วิเคราะห์โครงสร้างไฟล์งานเดิมที่ใช้ออกแบบระบบ
  SHEET_SCHEMA.md      โครงสร้างฐานข้อมูล Google Sheet ทั้ง 6 ชีต
  DEPLOYMENT.md        ขั้นตอนติดตั้ง/ดีพลอยละเอียด
sample-data/          ข้อมูลตัวอย่าง (สมมติ ไม่ใช่ข้อมูลจริง) สำหรับทดสอบระบบ
```

## เริ่มต้นใช้งาน

ดูขั้นตอนละเอียดที่ [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) โดยสรุป:

1. สร้างโปรเจกต์ Google Apps Script แล้วคัดลอกไฟล์จาก `apps-script/` ทั้งหมด
2. รันฟังก์ชัน `initializeSystem()` หนึ่งครั้ง (สร้างฐานข้อมูล Google Sheet ให้อัตโนมัติ)
3. Deploy เป็น Web app แล้วเข้าใช้งานด้วย `EmployeeID: admin`, `PIN: 123456` (ระบบจะบังคับเปลี่ยนรหัสผ่านทันที)

## หมายเหตุด้านความปลอดภัยของข้อมูล

ไฟล์ต้นฉบับที่ใช้วิเคราะห์เพื่อออกแบบระบบนี้มีข้อมูลส่วนบุคคลของลูกจ้างจริง (ชื่อ-สกุล, เลขบัญชีธนาคาร)
**repository นี้จึงไม่ได้เก็บข้อมูลจริงเหล่านั้นไว้เลย** — เอกสารวิเคราะห์และข้อมูลตัวอย่างทั้งหมดใช้ชื่อ/ตัวเลขสมมติ
ผู้ดูแลระบบจะเป็นผู้กรอกข้อมูลลูกจ้างจริงลงในระบบเองหลังติดตั้ง ผ่านหน้า "ทะเบียนลูกจ้าง"
